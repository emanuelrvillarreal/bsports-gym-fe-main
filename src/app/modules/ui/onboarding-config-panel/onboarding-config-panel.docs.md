# Onboarding Config Panel

Panel de administración para revisar y relanzar tours de driver onboarding por rol.

## Archivo

- [onboarding-config-panel.component.ts](./onboarding-config-panel.component.ts)

## Cuándo usarlo

Montar en una pantalla de configuración o sysadmin cuando la app define tours en [driver-onboarding.registry.ts](../driver-onboarding/driver-onboarding.registry.ts).

## Directiva asociada

- [config-role.directive.ts](./config-role.directive.ts) — filtra pasos visibles según rol del usuario.
