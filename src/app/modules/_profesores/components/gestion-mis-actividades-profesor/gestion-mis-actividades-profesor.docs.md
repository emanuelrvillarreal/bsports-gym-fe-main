# GestionMisActividadesProfesorComponent

`app-gestion-mis-actividades-profesor` muestra las actividades asignadas al profesor, con paginación y detalle de cada actividad.

El listado usa `ActividadesApiService`; la acción de detalle muestra `app-load-spinner-blue` dentro de la acción de la tabla y el popup conserva el mismo feedback durante la consulta.
