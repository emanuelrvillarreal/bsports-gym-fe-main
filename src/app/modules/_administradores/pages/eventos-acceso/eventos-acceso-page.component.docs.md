# EventosAccesoPageComponent

Página delgada compartible por ADMIN y ADM_RECEPCION. Presenta el hero “Entradas a eventos” y delega listado, ABM y operación a `app-gestion-eventos-acceso`.

Rutas: `/admin/eventos-acceso` y `/adm-recepcion/eventos-acceso`. Ambas cargan este mismo componente y aparecen en el nav-bar como “Entradas a eventos”.
