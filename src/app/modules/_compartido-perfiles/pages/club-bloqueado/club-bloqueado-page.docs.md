# Club bloqueado

Pantalla privada sin layout ni navegación para una empresa cuyo `companyBlocked` está activo.
El ADMIN puede consultar y pagar la factura vencida más próxima; el resto de los perfiles solo
puede volver a verificar el estado o cerrar sesión. El desbloqueo se decide siempre con una sesión
actualizada, porque también puede depender de la vigencia de la suscripción CRM.
