# Periodicidad de cuotas

El contrato compartido para actividad (`periodicidadCuota`) y cuota social de empresa (`periodicidadCuotaSocial`) usa estos valores exactos: `SEMANAL`, `MENSUAL`, `BIMESTRAL`, `TRIMESTRAL`, `CUATRIMESTRAL`, `SEMESTRAL` y `ANUAL`.

La interfaz exporta el tipo literal `PeriodicidadCuota` y el catálogo visible en español para los selects. El valor inicial de los formularios es `MENSUAL`. Los días de vencimiento se conservan como campos independientes.
